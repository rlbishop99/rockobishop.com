Micro Scope

← Back to Projects
Play Micro Scope on itch.io ↗

Micro Scope is a game that I developed with a partner for a 3-hour Game Jam. We each had our own set of tasks to complete, and we collaborated closely to ensure that the game was both fun and polished. I worked for 3 hours, then my partner worked for 3 hours, and we were able to create a complete game in that time. The game is very simple: find the odd-one-out Virus, click on it, and perform a quicktime event. You have two minutes to find as many viruses as you can.

The game doesn't feel great, and looks even worse, but it was a fun experience to make a game in such a short amount of time. I learned a lot about working with a partner, and how to make a game that is both fun and "complete" in a very short amount of time.
