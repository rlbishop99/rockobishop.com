Illusio Fracta

← Back to Projects
Play Illusio Fracta on itch.io ↗

Illusio Fracta is a puzzle game that I developed over one week for a Game Jam. The goal of the game is to stop the Illusionist from wreaking havoc on the land. The game is a cross between a Text-Based RPG and Spot the Difference, where you can only interact with the world by typing in commands. The game is a bit of a throwback to the old text-based adventure games, but with a modern twist where you can only interact with objects you've most recently seen when your eyes are open, and the scene changes every time you open your eyes.

I'm very proud of this game, as it was the first time I had ever made a game that was fully text-based. It was also the first time I had ever made a game that was fully playable from start to finish that I felt was actually fun and engaging to play. I learned a lot about parsing user input, how to create puzzles that were challenging yet accessible, and about manipulating game state and tracking that state across sessions.
